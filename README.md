uses: triggers a build in jenkins automatically depending on time and commit changes or neither of them or bothe of them
3 types of triggers
1. POll Scm: it is dependent on the time and commits within in the time so that it triggers a build i.e it needs atleast a single commit in the github to trigger a build with in the specified time.
   
2. Webhooks : it is independent of time it just trigger a bulds when any changes are commited
   
3. Build Periodically: its similar to poll scm but independent of commit changes it automatically triggers a builds in jenkins at a specifies time.
